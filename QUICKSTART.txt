XanDesk Windows preview

1. Keep XanDesk.exe, arcdesk-relay.exe, and all DLL files together.
2. On the host PC, run XanDesk.exe. It starts minimized to the Windows system tray.
3. Right-click XanDesk in the tray, open the app to configure the relay URL, then Pair this PC... to start the host and open the owner dashboard with the code prefilled.
4. Sign in, choose Add PC, and submit the code. The account backend must be deployed for this final enrollment step; the Rust preview relay alone does not provide it.
5. Once a device is enrolled by the account backend, an authorized viewer connects from the dashboard. The host must stay powered on, online, and unlocked.

For remote access, the host's relay address must be a public HTTPS/WSS endpoint. Cloudflare Pages hosts the website, not the Rust signaling relay. Deploy the relay and account/device/session API separately; configure ARCDESK_ORIGINS to include the Pages origin. See README.md and SETUP-PAGES.md.

To go offline, choose Pause (go offline) from the tray menu. Keep the pairing code private. This preview does not run as a Windows service or start with Windows.

This is an early Rust implementation, not full DextraDesk feature parity. Screen video, keyboard/mouse, optional text clipboard, and measured stream FPS are included. Audio, controllers, file transfer, account backend, GPU encoding, and lock-screen access are not implemented.
